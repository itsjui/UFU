Tipo de nós DOM tree



    
O código da página, inicialmente, itera sobre todos os nós filhos da tag body e expõe o objeto html para cada filho (Text, HTMLHeadingElement, HTMLInputElement, Comment, HTMLPreElement, HTMLScriptElement). Vemos '[object HTMLHeadingElement]', [object HTMLInputElement] e etc. pois todos os nós html são representados como objetos.

        Em seguida, é checado se o input presente na página é instância das seguintes classes/interfaces: HTMLInputElement, HTMLElement, Element, Node e EventTarget. Todas as checagens retornam true devido à hierarquia de classes e interfaces: HTMLInputElement -> HTMLElement -> Element -> Node -> EventTarget, o que faz com que o input seja uma instância de todas essas.
        
        Por último é exposto o tipo do nó do document, sendo HTMLDocument.
